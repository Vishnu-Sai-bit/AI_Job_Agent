# Power BI Executive Dashboard Assets

This directory contains DAX calculation measures, Star Schema data model documentation, and export templates for Power BI connectivity.

### Key Metrics Tracked
- **ATS Compatibility Rate (%)**: `DIVIDE([Total Points Earned], 100)`
- **Conversion Ratio (%)**: `DIVIDE([Interview Count], [Applied Count])`
- **Application Velocity (Days)**: `DATEDIFF([Saved Date], [Applied Date], DAY)`
